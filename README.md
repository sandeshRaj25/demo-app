# Vercel Flask Hello UI

A simple Flask application that:

1. Displays a textbox.
2. Accepts the user's name.
3. Calls the Python backend.
4. Displays "Hello <name>".

## Project structure

vercel-flask-ui-hello/
├── app.py
├── requirements.txt
├── vercel.json
└── templates/
    └── index.html

## Local run

Install dependencies:

pip install -r requirements.txt

Run:

python app.py

Open:

http://127.0.0.1:5000

## Vercel

Push the project to GitHub and import it into Vercel.
